# NICA TECH CONCEPT — Website v2

A responsive GitHub Pages-ready website for NICA TECH CONCEPT.

## Files
- `index.html` — main site
- `style.css` — theme and responsive layout
- `script.js` — mobile menu and current year
- `assets/nica-tech-logo.png` — extracted from the supplied NICA TECH artwork
- `assets/nica-tech-mark.png` — extracted logo mark
- `assets/brand-board.jpg` — supplied brand artwork

## Theme
- Deep Navy: #07111F
- Secondary Navy: #0B1A2A
- Electric Blue: #168CFF
- Cyan: #55D8FF
- Cool White: #F6F8FB

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
5. Open `https://YOUR-USERNAME.github.io`.

The illustrations in the project cards are CSS/vector artwork, so the site does not depend on third-party image URLs.
