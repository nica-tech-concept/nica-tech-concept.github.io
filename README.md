# NICA TECH CONCEPT Website

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will publish the site at your Pages URL.

Before launch, replace placeholder social links and email with your exact official accounts. Add your official logo/project images when ready.
